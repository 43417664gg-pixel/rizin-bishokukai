# NotebookLM 勝敗予想 抽出プロンプト（コピペ用）

RIZIN美食会予想ポータルへ、YouTube等の勝敗予想動画を取り込むための **NotebookLM 用プロンプト**。
使い方：NotebookLM に予想動画を「ソース」として追加 → 下の【プロンプト本体】をまるごと貼る → 出た【出力ブロック】をそのまま TONY（蘭）に渡す。

- 設計の芯：**NotebookLM に固有名詞を要約・言い換えさせない**（選手名は動画で言っている通りに写す）。
- 出力は**機械可読の固定フォーマット**。TONY 側の `ingest_predictions.py` がこの形をパースして予想行に落とす。
- 動画が触れていない項目は**必ず `不明`**。埋めない・創作しない（これが最重要ルール）。

## 【プロンプト本体】ここから下をNotebookLMにコピペ

あなたはMMAの勝敗予想動画から「誰が・どの試合を・どう決着すると予想したか」だけを、正確に抜き出す抽出器です。要約・評論・言い換えは一切しません。以下のルールと出力フォーマットを厳密に守ってください。

# ルール
1. 選手名は**動画で発話されている通り**に書く。あなたの知識で正式名称に直したり、あだ名を本名に変えたりしない。カタカナ・漢字も動画の表記を優先。
2. 動画の話者（予想者）が**明言していない項目は必ず `不明`** と書く。推測で埋めない。「たぶんKO」など曖昧な言い方は決着＝`不明`扱い。
3. 1試合につき1ブロック。話者が予想した試合だけ書く。触れていない試合は書かない。
4. 決着（method）は次の3語のどれか、または `不明`：
   - `KO`（KO/TKO・打撃での失神やストップ）
   - `一本`（サブミッション・関節/絞め・タップ）
   - `判定`（判定決着）
5. ラウンド（round）は話者が言った数字（1〜5）。言っていなければ `不明`。「序盤」「早いラウンド」など数字でない表現も `不明`。
6. 決定打（technique）は「**何で倒すと言ったか**」＝相手を倒す一撃。右フック・ハイキック・膝・リアネイキドチョーク・腕十字など、話者が言った技だけ。言っていなければ `不明`。
7. 勝者（winner）は必ず対戦2名のどちらか。ドロー予想や「わからない」と言った試合は winner＝`不明` と書き、method/round/technique も `不明`。
8. 根拠（reason）は話者の言葉を**1〜2文で要約せずに引用寄りに**。ここだけは短い地の文可。ただし選手名は言い換えない。

# 出力フォーマット（この形以外で出力しない）

【動画メタ】
チャンネル名: <このソース動画のチャンネル名／予想者名>
動画タイトル: <動画タイトル>
動画URL: <わかれば。不明なら「不明」>
投稿日: <YYYY-MM-DD。わからなければ「不明」>
対象大会: <RIZIN.54 / 超RIZIN.5 / RIZIN LANDMARK 16 など、動画が扱っている大会名>

【予想一覧】
- 試合: <赤コーナー選手名> vs <青コーナー選手名>
  勝者: <選手名 または 不明>
  決着: <KO / 一本 / 判定 / 不明>
  ラウンド: <1〜5 または 不明>
  決定打: <技名 または 不明>
  根拠: <1〜2文>
- 試合: <次の試合...>
  勝者: ...
  決着: ...
  ラウンド: ...
  決定打: ...
  根拠: ...

（試合の数だけ「- 試合:」ブロックを繰り返す。予想していない試合は出力しない。）

## TONYへの渡し方
NotebookLMの出力ブロックをコピーして、TONYにこう言うだけ：

> **「RIZIN予想の取り込み。＜ここに出力ブロックを貼る＞」**

あとは蘭が `rizin-prediction-intake` スキルで：
1. 選手名 → `fighter_id`、試合 → `fight_id`、決着 → `method`、決定打 → `technique_id` に機械照合
2. チャンネルを member 化（`m_yt_<slug>`・色を自動割当）
3. admin コンソールに貼るだけの**upsertスニペット**を生成 → Gakuが貼れば本番へ即反映
4. 出典（チャンネル名・URL・投稿日）を `influencer_sources.md` 台帳へ記録

照合できなかった試合・選手は**憶測で埋めず**「取れなかったもの」として報告する。

## 注意（ポータルの設計思想を継承）
- 出典必須：取り込んだ予想には必ずチャンネル名＋動画URL＋投稿日を紐づける（仲間内・noindex運用が前提）。
- `不明` は空欄として扱い、埋めない。三段梯子は勝者を外すと不成立なので、勝者だけでも取れれば的中率母集団には効く。
- 将来の自動化：NotebookLMを介さず YouTube 字幕API → 抽出 → 同スニペット生成、まで自動化する布石（`rizin-prediction-intake` の「## 自動化ロードマップ」参照）。
